Kinetry, for builders.

Kinetry turns learning content and a brand into a short, narrated video. It's an engine, not an editor. You call it from your own platform, with your own AI keys, and keep everything it makes.

How it works

Give Kinetry a lesson, guide or policy and a company website. A model decides what to say, how the brand looks and which look fits. Everything after that is plain code, so the same plan, brand and voice always give the same frames.

BrandColors, fonts and logo read from the website, once.
DirectA creative director picks style, format and pacing.
PlanThe script, written as scenes from a catalog.
Voice and fitEvery line voiced and measured; every text checked to fit.
RenderAn MP4, QA frames and a report.

You can review and edit the plan (plain JSON) before rendering, or skip planning and render a plan you wrote. Every model output is recorded, so any run can be replayed without calling a model again.

Features

Reads what you already haveMarkdown, Word, PowerPoint (with speaker notes), PDF, web pages, and audio or video recordings.
Your brand, from your websiteColors, fonts and logo captured once and saved as a brand pack. Contrast is enforced to WCAG AA.
Hundreds of looks28 scene types, 57 layouts, 7 styles and 3 formats (16:9, 9:16, 1:1), plus 9 transitions.
Seven video kindsLesson, course summary, session recap, explainer, how-to, announcement and onboarding, each with its own structure.
Narration that matches the screenEach item appears exactly when it's said. Two-person dialogues use a voice per speaker.
Many languagesCaptions, local voices for seven languages, cloud voices for the rest, and right-to-left layouts.
Motion layersOpt-in camera moves, kinetic type, ambient light, animated illustrations and a 3D stage.
The brand's own 3D modelsProducts or mascots shared as .glb files, placed by an asset agent where each scene has room.
Text that always fitsEvery line is measured. Too long: type shrinks a step, then a fast model shortens the copy.
Any model, your keyAnthropic, OpenAI, Bedrock, Gemini, Azure or any compatible endpoint. Keys never reach logs or reports.
Voice checkOptional speech-to-text pass that flags any line whose audio doesn't match the script.
Runs where you runYour servers or cloud, with Docker, systemd or Lambda rendering. Finished videos can go straight to S3.

Quick start

Needs Python 3.10+, Node.js 22+ and FFmpeg.

Private preview. The repository isn't public yet. Ask for access to install it.
# install, then fetch the pinned renderer and browser
pip install "kinetry[llms,kokoro] @ git+ssh://git@github.com/MSBeni/kinetry.git"
kinetry setup
kinetry doctor

# a brand, a plan you can review, then the video
kinetry brand https://example.com --save brands/example
kinetry plan  lesson.md --section 2 --out plan.json
kinetry run   --plan plan.json --brand brands/example --out lesson.mp4

# or in one step, choosing the look yourself
kinetry run lesson.md --style warm --format 9:16 --captions --effects subtle --out shift.mp4

Optional extras: bedrock, anthropic, openai, google (or llms for all four), kokoro (free local voice), docs (Word, PowerPoint, PDF), service, mcp, or all.

Or describe the video in plain words and let the brief agent fill in the request:

kinetry brief "a 60-second vertical how-to for new nurses on hand hygiene, in Spanish, with captions"

Python API

For a Python service, a pipeline step or a batch worker:

from kinetry import Kinetry, load_source

tf = Kinetry(llm="anthropic:claude-sonnet-5-5")       # or openai:..., bedrock:<model id>, ...
pack = tf.brand("https://example.com")                  # BrandPack: kit + logo; pack.save("brands/example")
plan = tf.plan(load_source("lesson.md", section=2), brand=pack,
               design={"format": "9:16"})              # a VideoPlan: review, edit, store
tf.preview(plan, brand=pack, out_dir="storyboard")      # one silent frame per scene, in seconds
result = tf.render(plan, brand=pack, out="lesson-2.mp4", music="bed.mp3")
print(result.status, result.video, result.qa_frames)

result.status is done, needs_review (text still didn't fit after the repair rounds), check_failed or error. report.json in the run folder says why.

HTTP service

For other languages, many callers or a queue: run kinetry serve or the Docker image. Jobs start, you poll or get a signed callback, and finished videos can be uploaded to S3-compatible storage.

EndpointWhat it does
POST /v1/brandsRead a brand from a website: {"url": "https://customer.example"}
POST /v1/sourcesUpload a .docx, .pptx or .pdf and get its sections (/v1/sources/url for a web page)
POST /v1/briefsTurn a chat message into a structured request
POST /v1/plansWrite the plan from a source and a brand
POST /v1/videosRender a plan (add callback_url to be called back)
GET /v1/videos/{id}Job status, the video, and the model and voice used
GET /v1/catalog, GET /v1/kindsEvery style, scene type, layout and video kind
 
curl -X POST https://kinetry.your-company.internal/v1/videos \
  -H "Authorization: Bearer $KINETRY_API_KEY" -H "Content-Type: application/json" \
  -d '{"plan": {...}, "brand_id": "acme", "voice": "kokoro:af_heart",
       "callback_url": "https://lms.example/hooks/video-ready"}'

Each request can bring its own model and key ("llm": {...}). Operators decide whether callers may choose models and voices.

A second, cheaper model can handle copy rewrites (--llm-fast). Models without tool calling work through a JSON-schema fallback.

Cost: about $0.06–0.11 in model calls for a 90-second video with Claude Sonnet on Bedrock and the free local voice. Cloud voices cost extra. A render takes about 4–5 minutes on 2 vCPUs.

The local voice narrates English, Spanish, French, Italian, Brazilian Portuguese, Hindi and Mandarin. Cloud voices cover Japanese, Farsi, Arabic, Hebrew, Urdu and more, and right-to-left scripts are laid out right to left. Voice cloning is off unless the operator turns it on, and always needs a consent recording from the speaker.

Leave any choice to the creative director or pin it. A brand profile holds a company's standing choices: allowed styles, a format, voices per role, a music bed.

Brands and 3D

  • Text colors are darkened until they pass WCAG AA on the video's background.
  • Proprietary fonts are swapped for close open fonts, and every swap is logged.
  • The logo is dropped, with a note, if it wouldn't stand out on the background.
  • A brand's own 3D models (.glb, up to 25 MB) are checked, described and placed by an asset agent. The logo's symbol can be cut out and extruded in 3D for the opening and closing scenes.
kinetry assets3d brands/acme add scooter.glb --role hero
kinetry assets3d brands/acme mark          # cut the symbol out of the logo
kinetry run lesson.md --brand brands/acme --depth subtle --out lesson.mp4

Use a company's logo, fonts and models only with its permission.

Limits

  • Narration is written by a model. It sticks to the source's facts, but keep a human review step for anything learners see.
  • A source is limited to about 12,000 words (25 pages). Longer documents become one video per section.
  • Scanned PDFs, legacy .doc and .ppt, and course export zips (SCORM, Common Cartridge) aren't read yet.
  • A render uses about 2 vCPUs for 4–5 minutes per 90 seconds of video. Scale out with more workers.
