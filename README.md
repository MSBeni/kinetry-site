# kinetry.xyz

The Kinetry website: one static page, served by GitHub Pages at https://kinetry.xyz.

- `index.html`: the page (no build step)
- `media/`: showcase videos and their posters, all made with Kinetry for fictional brands
- `fonts/`: Anybody and Hanken Grotesk, self-hosted under the SIL Open Font License (see the OFL files)

The 3D models in the furniture video are Khronos glTF sample models by Eric Chadwick, © Wayfair LLC: Sheen Chair (CC0), Glam Velvet Sofa, Iridescence Lamp and Anisotropy Barn Lamp (CC BY 4.0, https://creativecommons.org/licenses/by/4.0/). The onboarding video uses Diffuse Transmission Plant (Eric Chadwick, CC BY 4.0; Rico Cilliers, CC0), Diffuse Transmission Teacup (Poly Haven and Eric Chadwick, CC0), Lantern (sbtron, CC0) and Glass Vase Flowers (Eric Chadwick and Rico Cilliers, CC0).
